# x264 QP Analysis

## Overview

This script analyses the x264 encoder for Quantization Parameter (QP) values from 0 to 51. For each QP value, it runs an encode and collects:

- Output file size in KB
- Encoding speed in frames per second (FPS)

The script writes the collected data to `results.csv` and creates `x264_qp_report.xlsx`, which contains the results and two line charts: QP vs File Size and QP vs Encoding FPS.

## Prerequisites

- Windows
- Python 3
- `x264.exe`
- `foreman-cif.yuv` input video
- Python package `openpyxl`

Place `x264.exe` and `foreman-cif.yuv` in the same working directory as `x264_analysis.py`, or update the paths at the top of the script.

Install the Python dependency from Command Prompt:

```cmd
python -m pip install openpyxl
```

## How to Run

1. Open Command Prompt in the directory containing `x264_analysis.py`, `x264.exe`, and `foreman-cif.yuv`.
2. Run:

   ```cmd
   python x264_analysis.py
   ```

3. Wait for the runs for QP 0–51 to complete.
4. Open `results.csv` or `x264_qp_report.xlsx` to review the results.

## Outputs

- `results.csv` — QP, file size in KB, and encoding FPS for each successful run.
- `x264_qp_report.xlsx` — formatted results, file size in MB, and two charts.
- `output_qp0.264` through `output_qp51.264` — encoded output files generated by x264.

Each run recreates `results.csv` and `x264_qp_report.xlsx`. The encoded `.264` files are written to the working directory and may be overwritten when the script runs again.

## Notes

The script uses a resolution of `352x288` and sets `--qpmin 0` so the full requested QP range, including QP 0–4, can be processed. If an individual x264 run fails or its FPS value cannot be parsed, that QP is skipped and will not have a data row in the CSV.

## Conclusion

Increasing QP generally results in smaller output files and higher encoding FPS. Individual values may fluctuate, so the results should be interpreted by looking at the overall trends rather than expecting a perfectly consistent change at every QP step.
